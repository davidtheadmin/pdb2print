# Guaranteed-watertight mesh booleans/offsets (analytic tube-slab; same kernel
# as the planned client-side WASM build). Required by the nucleic-acid path.
#
# PINNED, and it has to stay pinned. tube_slab hands this kernel one flat union
# of every primitive in a chain rather than a tree of small ones, and the result
# is not identical between the two: the same primitives fused flat come out ~0.6%
# smaller with ~11% fewer triangles (measured 2026-07-30 on 1BNA). That is fine
# — it is microns of wall — but it means the exported mesh depends on how this
# version handles a large batch boolean. An unpinned floor would let a fresh
# Docker build resolve a different version than the one the meshes were checked
# against, and the disk cache would then hold entries from both.
#
# To move it: bump here, rebuild the cache, and re-check a nucleic build against
# a render before deploying.
